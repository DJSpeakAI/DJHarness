# 安装指南 📖

## 前置条件

1. Node.js（建议 20+）
2. 官方 DeepSeek Harness：

   ```bash
   npm i -g @deepseek-ai/dsh
   ```

3. 至少完整启动过一次 DSH（会生成 `~/.dsh` 配置目录和默认 profile）。

## 一键安装

```powershell
git clone <本仓库地址> DJH-open
cd DJH-open
powershell -ExecutionPolicy Bypass -File install.ps1
```

脚本做了三件事：
1. 把 `plugins\` 下 27 个插件复制到 `%DSH_HOME%\profiles\web\plugins\`
2. 在 `profiles\web\node_modules\@local\` 建 junction
3. 在 `profiles\web\package.json` 写入 `link:` 依赖（原文件自动备份为 `package.json.bak-djh-install`）

**重启 DSH**，插件即装载。卸载：`install.ps1 -Uninstall`。

## 需要 API key 的插件

源码里没有任何密钥。以下插件需要你自己在运行时目录放配置：

| 插件 | 配置位置 | 说明 |
| --- | --- | --- |
| `dsh-tts-voice` | `<工作区>/apps/` 各家 TTS key | 不配也能用 DeepSeek 官方 TTS |
| `dsh-status-pills` | 各平台 `secrets/token.dpapi` | 不配只显示内存胶囊 |
| `dsh-model-hub` | 模型聚合平台 key（可选） | 官方 DeepSeek 模型开箱即用 |

## 官方包补丁（可选，进阶）

我们的安装里对官方 node_modules 做过一些小补丁（删掉不想要的命令、调整用量显示等）。这些补丁**升级 DSH 后会被覆盖**，且需要重启。本仓库暂不打包补丁脚本——建议先用纯净插件跑起来，需要再按 `docs/` 里的说明手动改。这层保持简单，避免补丁和你的 DSH 版本不匹配。

## 自动化任务建议（可选）

DSH 的自动化任务绑定会话，无法随仓库分发。推荐自建：

- **每日积分领取**（08:00）：读签到脚本 status.json 汇报
- **AI 新闻搜集**（09:00）：web_search 挑 8~10 条写入 JSON，供 `dsh-ai-news` 面板展示

## 常见问题

- **重启后插件没出现**：确认 `package.json` 里有 `link:` 依赖、junction 存在，再看 DSH 日志有没有加载报错。
- **界面白屏**：一次性禁用全部 client 插件排查（把 `@local` junction 临时改名），定位到具体插件再反馈 issue。
